The exact clipboard share text for a finished run, verbatim from each game's design document (ROTATE-LOCK.md §17.4, DIFFERENCE-RELAY.md §17.4): title line (game, puzzle number, tier, the game's own count — moves for ROTATE LOCK, runs of six for DIFFERENCE RELAY), an emoji grammar block, and the suite URL. No color: the grammar is shape-and-fill only (filled square = a new arrangement or a solved run, hollow = a revisit or an empty run, black = unused padding) so it reads the same copy-pasted anywhere, with no design-system styling at all — that is the point of a share block.

Two different grammars, both suite patterns, not invented per game: ROTATE LOCK's grammar B rows are 8 wide and only as tall as the moves need (a revisit is a hollow square, not a wrong move — the lock has no wrong moves, only retraced ones); DIFFERENCE RELAY's grammar A rows are a fixed 5 wide, one row per run, and a full row of filled squares is a solved board. `CopyBox` renders it read-only, same as any other share text.

The three word games add their §27 examples verbatim (WORD-LADDER.md, PANGRAM.md, FIVE-LETTERS.md). Their rows use the suite share vocabulary's tier glyphs (`src/shared/share-vocabulary.ts`): ⭐ best, 🔷 strong, 🟩 partial, 🟠 weak, 🔻 miss, plus the fill squares 🟦 ⬜ and ⬛ unused. Each token is a different shape as well as a different hue, so a share block survives greyscale. No row names a word, a letter or a position: FIVE LETTERS sorts each row's marks precisely because positional rows measurably leak the answer.
