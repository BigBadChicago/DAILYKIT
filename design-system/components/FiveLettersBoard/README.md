FIVE LETTERS: six guess rows of five tiles, then a seven-column keyboard whose keys keep the best mark each letter has earned. Ported from `src/games/five-letters/` (`fl-*`).

`FiveLettersBoard({status, rows[], keyMarks})`; a row is `{word, marks[5]}` (0 absent, 1 present, 2 right), `{draft}` while typing, or omitted when unused. **Marks are shapes first** (FIVE-LETTERS.md, marks): *right* is a filled tile with a filled dot `●`, *present* a dashed 3px border with a hollow dot `○`, *absent* a plain tile with a cross `×`, dimmed, and a struck-through key. Deliberately not the green / yellow / grey convention other letter games use: colour here is one accent hue, and the shapes carry the meaning, so it reads in greyscale and high contrast. Keys are 45.4 by 52px at 360px (column gap 3px, not 6, or the row overflows). Set `--accent` to `game-five-letters` (hue 288: 7.1:1 white text light, 5.1:1 dark).
