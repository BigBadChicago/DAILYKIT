PANGRAM: a score meter of eight cells, the word being typed, seven letter keys four over three, Delete / Shuffle / Enter, a two-tap Finish, and the words found. Ported from `src/games/pangram/`, with the classes renamed `pan-*`: the source uses `pg-*`, which POKER GRID already owns in this one stylesheet (the two games never share a page in the app).

`PangramBoard({status, meter, draft, letters[7], found[], confirming})`. `letters` is in keypad slot order: slots 0–3 the top row, 4 / 5 / 6 the bottom row, and **slot 5 (bottom middle) is always the centre letter**. The centre key is marked three ways, never colour alone: a 4px accent border, an underline, and `, centre letter` in its accessible name. It is a plain 4-over-3 keypad, deliberately not a honeycomb of hexagons (PANGRAM.md 5; BACKLOG.md, trade dress). A pangram in the found list is bold, underlined and labelled `(pangram)`. Finish asks for a second tap before it ends the day. Set `--accent` to `game-pangram` (hue 208: 5.7:1 white text light, 6.5:1 dark, no contrast flag).
