# ASSETS

Every asset shipped in a build appears here with its origin and license. An
asset with no row here does not ship.

Admissible origins, per Section 8.6: system provided, self drawn in this repo,
or third party under a license permitting commercial use with the license text
vendored alongside.

| Asset | Path | Origin | License | Notes |
|---|---|---|---|---|
| System UI font stack | ui/chrome.css | System provided | n/a | No webfont ships in version 1, keeping the byte budget clean |
| Card faces | games/poker-grid/render.ts | Self drawn | Repo license | Suit pips drawn as inline SVG paths authored here, not traced from any deck |
| Share glyphs | contract/types.ts palettes | Unicode | n/a | Codepoints are not copyrightable; rendering is the platform's font |
| Suite icon, vector | static/icon.svg | Self drawn | Repo license | Five rounded squares in a quincunx, one per game. Authored here as plain SVG rects |
| Suite icon, raster | static/icon-192.png, static/icon-512.png | Self drawn | Repo license | Rendered from the same geometry as icon.svg. Needed because the web manifest install prompt does not accept SVG on every platform |
| Web app manifest | static/site.webmanifest | Self authored | Repo license | Names, colors, and the icon list. Not an asset with a third party origin, recorded here because it ships |
| Direction arrows | games/vector/render.ts | Self drawn | Repo license | Four arrow glyphs as inline SVG paths authored here, no font and no emoji on the board. Arrow and ray counting puzzles appear in published catalogues under proprietary genre names; no such name appears anywhere in the product or this repository |
| LETTER TRAIL answer list | data/letter-trail/answers.txt | Derived: ENABLE intersected with wordfreq top 30000 | Public domain (ENABLE) and Apache 2.0 (wordfreq) | Build time input only, never served to the browser. ENABLE released to the public domain by Alan Beale; wordfreq is Apache 2.0 by Robyn Speer. The intersection keeps only words that are both dictionary valid and common. A reviewed profanity and slur stop list is subtracted once at curation, below |
| LETTER TRAIL themes | data/letter-trail/themes.json | Self authored | Repo license | Build time input only, never served. Curated groups of related common words, each a subset of the answer list, from which a day's board draws its words. Curation is one time, not daily, so it does not breach the zero daily content cost rule |
| ENABLE dictionary | data/letter-trail/enable.txt | Alan Beale | Public domain | Build time input only, never served. Used by the generator and verifier to enumerate every word present on a board for the difficulty measure and the span uniqueness proof |
| wordfreq | build dependency, package.json devDependencies | Robyn Speer | Apache 2.0 | Build time only Python package that produces the frequency ranked word list the answer list is derived from. Runs in the list preparation step, never in the browser bundle |
| LETTER TRAIL stop list | data/letter-trail/stoplist.txt | Self authored, seeded from a public profanity list | Repo license | Build time input only, never served. Words subtracted from the answer list at curation so no board can contain a slur or profanity. Reviewed by a person |
| WORD LADDER accepted list | src/games/word-ladder/words.ts, data/word-ladder/accepted.txt | Derived: ENABLE intersected with SCOWL/ESDB size 50 American | Public domain (ENABLE) and SCOWL permissive (see notice) | The one WORD LADDER runtime word asset: it ships in the browser bundle, because the player types free words that must be validated on device (unlike LETTER TRAIL, whose words are checked against the day's baked set and ships no dictionary). ESDB is a spell checker list that excludes proper nouns by construction, which wordfreq does not, so WORD LADDER uses ESDB rather than the LETTER TRAIL wordfreq source; the two word games deliberately keep two family sources (WORD-LADDER.md 12, BACKLOG.md). Length four, lowercase a to z, minus the deny list, about 2,332 words, about 5.5 KB gzipped. The SCOWL copyright and permission notice ships on the About page |
| WORD LADDER familiar list | data/word-ladder/familiar.txt | Derived: ENABLE intersected with SCOWL/ESDB size 35 American | Public domain (ENABLE) and SCOWL permissive | Build time input only, never served. Drives the fairness screen (at least one shortest path is all familiar words) and the generator's start and goal draw. About 1,909 words |
| SCOWL / ESDB word lists | build input, github.com/en-wl/wordlist at commit 1e5b7d3 | Kevin Atkinson and contributors | SCOWL permissive (copyright notice vendored, ships on the About page) | Build time only. The size classified spelling lists the accepted and familiar lists are derived from. The SCOWL Copyright file permits use, modification and redistribution including for commercial use, provided the copyright notice is retained, which the About page carries |
| Word game deny list | data/word-lists/deny.txt | Self authored, seeded from a public profanity list | Repo license | Build time input only, never served. The family deny list. Vulgar words, slurs and explicit terms subtracted from every derived word list. 22 four letter entries for WORD LADDER, extended to 89 of any length for PANGRAM on 2026-09-20; the extension is authored and awaits owner review on MANUAL-CHECKS.md section 7. WORD LADDER's committed list predates the extension (BACKLOG.md). The original 22 reviewed by a person |
| PANGRAM accepted list | data/pangram/accepted.txt | Derived by tools/pangram-words.ts: ENABLE intersected with SCOWL/ESDB size 50 American | Public domain (ENABLE) and SCOWL permissive (see notice) | Build time only, never served. Four letters and up, no s, at most seven distinct letters, minus the deny list, 18,598 words. The generator and the verifier derive every day's answers from it. The browser receives only each day's answer subset inside its manifest chunk, so the SCOWL notice on the About page covers what ships |
| PANGRAM familiar list | data/pangram/familiar.txt | Derived by tools/pangram-words.ts: ENABLE intersected with SCOWL/ESDB size 35 American | Public domain (ENABLE) and SCOWL permissive | Build time only, never served. A subset of the accepted list, 13,189 words. Drives the fairness screen and the pangram root draw |
| PANGRAM daily answers | data/pangram/manifest.*.json | Derived from the PANGRAM accepted list per day | As the accepted list | The one PANGRAM word data a player receives: each day's answers, obfuscated by the engine codec, about 8 KB gzipped per 31 day chunk |
| PANGRAM first session answers | src/games/pangram/tutorial.ts | Derived from the PANGRAM accepted list | As the accepted list | 21 familiar words for the fixed tutorial set, embedded because a tutorial has no manifest day; a test holds it to the list |
